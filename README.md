# EYE NINJA 👁️🥷

EYE NINJA is a professional eye-tracking Fruit Ninja style game built using Python, OpenCV, and Pygame.

## Features
- Eye tracking using webcam
- Blink detection for slicing
- Smooth gaze movement
- Slow motion ability
- Combo system
- Debug camera mode
- Multiple fruit types and bombs

## Technologies Used
- Python
- OpenCV
- Pygame
- NumPy

## Installation

Install required libraries:

```bash
pip install pygame opencv-python numpy
```

## Run the Game

```bash
python eye_ninja.py
```

## Controls

- Move Eyes → Aim
- Blink → Slice fruits
- SPACE → Start / Ability
- D → Debug mode
- P → Pause
- Q → Quit

## Project Idea
This project combines Artificial Intelligence concepts with computer vision to create a hands-free gaming experience using eye tracking.
